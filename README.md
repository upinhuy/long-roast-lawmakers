An entry for the [make.fun bounty "The Long Roast: Lawmakers and the File They Cannot Convert"](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7).

One satirical sentence, at most 320 characters, roasting the lawmakers who would regulate AI, crypto, and the internet — but cannot convert a file to PDF.

## The roast

> The lawmakers who just passed a 400-page act dictating exactly how AI must think, learn, and behave spent the morning emailing their aide — subject line 'URGENT!!!' — to ask how to turn the Word file into a PDF before the vote.

## How it works

`main.ts` (pure Node standard library, deterministic, no network) writes the single sentence to `/output/entry.txt` — or to `$OUTPUT_DIR/entry.txt` when `OUTPUT_DIR` is set.

```sh
node main.ts
```
